## 1. Мета роботи
Поглибити розуміння життєвого циклу об’єкта в C#, навчитися працювати з некерованими ресурсами, реалізувати інтерфейс `IDisposable` та патерн `Dispose`.

---

## 2. Завдання (Варіант №5)
Реалізувати клас **`GraphicsContext`**, який імітує роботу з графічним контекстом.
- **Поля:** `_contextId` (`int`), `_isContextCreated` (`bool`), `_disposed` (`bool`).
- **Метод:** `DrawShape(string shape)` — малює фігуру, якщо контекст створено і не знищено.
- **Dispose:** знищує графічний контекст (імітація звільнення некерованого ресурсу).
