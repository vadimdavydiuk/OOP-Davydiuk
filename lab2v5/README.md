# Лабораторна робота №2
**Тема:** Клас із кількома конструкторами. Життєвий цикл об’єкта.  
**Студент:** Давидюк Вадим  
**Варіант:** 5  

## Мета роботи
Навчитися реалізовувати перевантажені конструктори, дослідити порядок їх викликів за допомогою ланцюгового виклику `: this()` та зрозуміти основи життєвого циклу об’єкта в C#.

## Завдання (Варіант 5 — Клас City)
* Створити клас `City` із приватними полями `_name`, `_country`, `_population`.
* Реалізувати публічні властивості з валідацією (перевірка населення на від'ємні значення).
* Додати конструктор за замовчуванням із ланцюговим викликом `: this()` та параметризований конструктор.
* Додати деструктор для відстеження видалення об'єкта з пам'яті.
* Продемонструвати роботу класу в `Main`, включаючи примусовий виклик Garbage Collector (`GC.Collect()`).

## Висновок
Під час виконання лабораторної роботи №2 я навчився застосовувати перевантаження конструкторів та ланцюговий виклик `: this()`, що дозволило уникнути дублювання коду ініціалізації. Ознайомився з життєвим циклом об'єкта в C#, принципом роботи збирача сміття (Garbage Collector) та призначенням деструктора.
