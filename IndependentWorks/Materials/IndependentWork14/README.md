# Самостійна робота №14: Кейси Polly/Retry

Умови — у PDF поруч із проєктом. Для цієї роботи фіксованого варіанта за номером студента немає. Назву проєкту взято з методички; у №9 назва не задана, обрано IndependentWork9.

## Запуск

Потрібен .NET SDK 10. З папки `IndependentWorks`:

```powershell
dotnet run --project IndependentWork14/IndependentWork13 --configuration Release
```



Детальний опис, висновки та відповіді на контрольні запитання — у [REPORT.md](REPORT.md).

## Фактичний вивід

Час і випадкові затримки можуть відрізнятися на іншому запуску.

```text
Самостійна №14: Polly, три сценарії

1. Читання каталогу з БД: Retry після тимчасового розриву з'єднання.
Звернення до БД #1
Retry 1: Тимчасовий розрив з'єднання.; затримка 35 мс
Звернення до БД #2
Retry 2: Тимчасовий розрив з'єднання.; затримка 126 мс
Звернення до БД #3
Каталог: монітор, камера, навушники

2. Перевантажена черга: Circuit Breaker та перевірка відновлення.
Реальне звернення до імітованої черги #1
Черга перевантажена.
Реальне звернення до імітованої черги #2
Circuit: OPEN
Черга перевантажена.
Звернення заблоковано: callback не виконувався.
Circuit: HALF-OPEN
Реальне звернення до імітованої черги #3
Повідомлення прийнято.
Circuit: CLOSED
Фактичних викликів: 3 (третій запит був заблокований).

3. Повільний експорт звіту: Timeout зі скасуванням.
Експорт розпочато...
Timeout: перевищено 1 секунду.
Експорт скасовано політикою Timeout.
Усі зовнішні ресурси імітовані, мережевих запитів немає.
```
